数据说明

哪些是真的，哪些有局限

  • 真的：体验区的每个组合，都在 一家上海门店、同一时间段 用麦当劳官方 MCP 逐个核价，页面只是把结果原样展示。
  • 可复现：仓库里的 fixtures/ 保存了官方原始返回，npm test 离线回放就能复现 README 里的每个数字。
  • 局限：这是单店、单时段的快照，价格会随门店和时间变化；装上之后会用你自己的门店实时核价，以 App 显示为准。
  • 不做的事：不下单、不替你换主食、不劝你多买、不推荐买会员卡；只支持到店自取。
装到 WorkBuddy 等 AI 助手

三种用法，挑一个顺手的

先在 open.mcd.cn/mcp 用手机号登录、激活，拿到你自己的 MCP Token，写进本机的 ~/.config/mcd-advisor/.env（不要发给任何人）。已经在 WorkBuddy【连接器】里配好麦当劳 MCP 的，这一步可以跳过，脚本会直接用那份配置。

1装进 WorkBuddy / Claude Code

本仓库就是一个标准 Skill。装好后直接说「麦辣鸡腿堡加中薯中可乐，人民广场附近怎么买更划算」。

git clone https://github.com/wenboxia/mcd-advisor.git ~/.workbuddy/skills/mcd-advisor

WorkBuddy 也可以在【专家 · 技能 · 连接器】里直接导入这个文件夹。Claude Code 放进 ~/.claude/skills/mcd-advisor，Codex 等放进各自的 Skill 目录。

2一句大白话（DeepSeek）

在配置里加上 DEEPSEEK_API_KEY，用一句话提问；模型只负责听懂，价格仍然全部来自官方核价。

node bin/mcd-advisor.mjs --ask "中午想在上海人民广场吃个麦辣鸡腿堡，配中薯和可乐"

3命令行（开发者）

零依赖，Node.js 18+。加 --json 给其他程序用；加 --replay 用录好的数据离线跑。

node bin/mcd-advisor.mjs "麦辣鸡腿堡 中薯 中可乐" --city 上海市 --near 人民广场
